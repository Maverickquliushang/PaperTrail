# PaperTrail v0.2.0

当前源码位于 code/。本次归档对应 CHANGELOG 同版本条目。

源码包 1285 个文件；静态站点包 1197 个文件。ZIP 文件列表与 CRC 已校验，SHA-256 见同目录校验文件。

源码恢复：解压到独立项目目录，按 README 与 code/local/README 安装锁定依赖。本地版需要 Python 3.11–3.13、Node.js 20.19+ 或 22.12+、uv；未生成本地版独立免安装运行包。

静态包解压后可部署到静态托管，或用 python -m http.server 本地预览；不要直接双击 HTML。后续自动采集需要源码包中的 GitHub Actions，静态 ZIP 自身不会更新。

不包含个人配置、飞书绑定、虚拟环境或开发缓存。仅包含公开论文元数据，不包含论文 PDF。
