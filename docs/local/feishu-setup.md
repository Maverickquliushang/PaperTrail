# 飞书接入

本地入口：`http://127.0.0.1:8000/#/feishu`。应用机器人长连接接收群内 @消息，发送由飞书消息 API 完成；不用把本地网页暴露到公网。首版一个应用、一个绑定群，只有绑定者能触发群聊指令。

## 创建并授权

优先在飞书接入页点击“准备飞书授权”，打开官方链接，登录并确认创建 PaperTrail 应用。使用官方 `lark-oapi` SDK 注册流程，最小模板只声明发送消息、接收群内 @消息权限及消息接收事件。成功后 App ID / App Secret 自动保存在项目内 `config/local/feishu.json`，不会通过状态接口返回密钥。

如果飞书里已有 PaperTrail，但本地仍显示未配置，重新授权时选择已有应用；不要重复创建。授权失败会显示不含密钥的原因，也可直接在开发者后台复制已有应用凭据到本地页面。

如果组织不支持快速创建，在[开发者后台](https://open.feishu.cn/app)创建企业自建应用，添加机器人能力。申请 `im:message:send_as_bot`、`im:message.group_at_msg:readonly`，把凭据填入本地页面。在“事件与回调”中选择长连接，订阅 `im.message.receive_v1`，发布应用版本并按组织要求审批，再把机器人加入目标群。

## 绑定与推送

在本地页面生成绑定码，然后在目标群选择 @机器人并发送 `绑定 <绑定码>`。绑定码 10 分钟有效。只有包含本机器人 @标记的近期群消息可以完成绑定；绑定本身不发送消息，页面会自动显示绑定结果。

点击“开启五个专区的每日推送”后，arXiv、OpenAlex、Hugging Face、顶会索引、OpenReview 的新定时推荐会在生成结束后依次发送，每个专区最多 10 篇。时间、主题由各专区的推荐设置控制，例如每天北京时间 09:00，关注计算机视觉、自然语言处理、图神经网络。同一天同一来源同一目标只投递一次；不自动投递开启前的历史、手动生成记录或综合推荐。失败/无新论文也以对应状态通知。

电脑与 PaperTrail 需运行。关闭或睡眠期间不保证按时发送；重启仍只处理当天、开启推送之后开始生成的定时推荐。关闭飞书连接暂停接收和推送，解绑同时关闭推送。

## 群聊工作台

每条消息先在飞书选中并 @PaperTrail。只有绑定者在绑定群可以操作。机器人与网页共用检索服务、推荐设置和历史；中文检索可使用下面的日常说法；推荐设置等管理操作仍使用表格中的明确指令。

### 直接用中文找论文

以下每条消息先 @PaperTrail，不必填写来源，也不要求“检索”后留空格：

- `检索图神经网络`
- `帮我找计算机视觉的论文`
- `搜索强化学习`
- `查一下图神经网络`
- `查找强化学习的论文`
- `搜索图神经网络`
- `自然语言处理`

默认请求全部五个来源，按日期从新到旧展示。中文主题中的常见研究术语按词组组合转换，英文原样保留；回复明确显示转换后的查询。仍可使用 `检索 arxiv 图神经网络 | 最近=30` 指定来源和筛选条件。

当前转换采用本地术语表，覆盖计算机视觉、自然语言处理、图神经网络等常见 AI 方向，不是通用翻译模型。未识别的中文、否定、备选条件或复杂限定不会被静默删掉，会先说明没有发起检索。支持“的、和、与、以及”作为已识别主题间的连接词；多个关键词用于同一次组合查询，不表示分别检索后取并集。普通中文查询不自动修改推荐主题或设置。

### 可选筛选与其他操作

| 网页功能 | 群聊用法（省略 @PaperTrail） |
| --- | --- |
| 多来源、关键词、日期、每源数量和取数排序 | `检索 arxiv,openreview graph neural network \| 最近=30 \| 数量=20 \| 排序=最新` |
| 指定日期与会议 | `检索 conferences computer vision \| 开始=2026-01-01 \| 结束=2026-10-18 \| 会议=ICLR,ICML` |
| 当前结果、分页 | `列表`、`下一页`、`上一页`、`列表 结果ID 2` |
| 结果排序 | `排序 最新`、`排序 最早`、`排序 标题`、`排序 相关性`；推荐用 `排序 推荐分` |
| 完整摘要、作者、标识符、原文、PDF、来源日期与推荐理由 | `详情 1`，或 `详情 结果ID 1` |
| 各来源状态、缓存时间与覆盖限制 | `来源`，或 `来源 结果ID` |
| 取消群内检索，保留已有结果 | `取消检索`，或 `取消检索 结果ID` |
| 最新推荐与历史 | `推荐 arxiv`、`历史 arxiv`、`历史 arxiv 2`、`推荐 arxiv 记录ID` |
| 查看某天推荐 | `推荐 arxiv 2026-10-18`；同一天多条记录需完整记录ID |
| 手动生成 | `生成推荐 arxiv`，结果进入网页同一历史 |
| 查看/修改推荐设置 | `设置 arxiv`、`设置 arxiv \| 时间=09:00 \| 数量=10` |
| 推送控制 | `推送`、`推送 开启`、`推送 关闭`、`推送 来源=arxiv,openreview` |
| 计划与任务概况 | `状态` |
| 完整说明 | `帮助`、`帮助 检索`、`帮助 推荐`、`帮助 设置` |

表格中参数使用半角竖线分隔。来源：`arxiv`、`openalex`、`huggingface`（可写 `hf`）、`conferences`（可写 `顶会`）、`openreview`、`all`（可写 `综合`）。检索中的 all 是五来源；推荐、历史、设置中的 all 是综合工作台，**不批量修改五个专区**。

检索数量是每个来源 1～50 篇；每页 10 篇，所有返回结果均可翻页。最近天数包含今天，不能同时填写开始/结束日期。群聊默认按日期从新到旧取数和展示；显式填写“排序=相关性”才按相关性检索。结果列表还可切换相关性/推荐分、最早或标题，不重新请求来源。日期以列表显示值为准，未知日期排最后；有限候选来源不保证检索到全站最新论文。日期、有限候选和顶会覆盖语义与网页相同。检索开始回复带检索编号，查看旧列表时可显式指定；通常只需发送“下一页”“详情 1”“来源”。列表写明合并去重后的总篇数、当前显示的论文范围和当前排序；来源状态使用中文，“只返回部分候选”表示覆盖限制，不等同检索失败。结果视图闲置30分钟过期，最多保留20个已完成视图，重启后需重新检索；推荐历史持久保存，可随时重新打开。检索中结果及序号可能随着新来源返回而变化。

推荐设置示例：

```text
设置 arxiv | 主题=computer vision;graph neural network | 时间=09:00 | 数量=10 | 自动=开启
设置 arxiv | 排除词=survey;vision | 回溯=30 | 去重=30 | 会议=ICLR,ICML,NeurIPS
设置 arxiv | 排除词=-
设置 all | 来源=arxiv,openalex
```

主题最多5个，排除词最多30个，使用分号分隔；时间为北京时间HH:MM，数量1～50，回溯及去重窗口1～365天，自动为开启/关闭。专区来源固定，只有综合可修改来源。全部参数校验成功后一次性保存，失败不部分覆盖。网页打开且没有未保存编辑时，会在轮询时同步群内修改；有未保存编辑时保留草稿，刷新页面可重新读取最新设置。

手动生成与网页共用全局互斥和去重；当天手动生成过推荐后，不再自动补跑当天。手动结果由当前指令回复，不进入定时推送队列。自动生成和推送是两个独立开关；推荐查看和自动推送也默认按日期从新到旧展示，未知日期排最后；不改写推荐历史与评分。每条自动推送仍最多10篇，更多结果可用推荐指令翻页。推荐分是规则排序，不代表模型分析或论文质量。

群里提供业务操作；应用凭据、授权、绑定/解绑、连接管理及投递记录仍在本地飞书接入页处理。`网页` 返回本机入口，手机不能用该地址访问电脑。收藏、笔记和 AI 分析在网页也尚未实现。

## 数据与验证边界

私有凭据在 `config/local/feishu.json`；事件去重、发送意图与结果在 `data/feishu-deliveries.json`，均被 Git 忽略。发送前先保存意图，使用稳定 UUID；确认成功、明确失败、结果不确定分别记录。发送超时、服务器异常或发送中崩溃时，不自动重发。状态接口只返回连接、绑定、投递概况，不返回 App Secret、访问令牌或消息正文。官方 SDK 在独立子进程中运行，日志只转译为连接状态，不记录长连接地址。

离线测试使用模拟飞书接口，浏览器测试使用独立配置或请求拦截，不连接真实群。新安装须自行完成授权、加群和绑定，并在自己的群内验证消息及定时推送。

官方参考：[Python SDK](https://github.com/larksuite/oapi-sdk-python)、[事件处理](https://open.feishu.cn/document/uAjLw4CM/ukTMukTMukTM/server-side-sdk/python--sdk/handle-events)、[发送消息](https://open.feishu.cn/document/server-docs/im-v1/message/create)。

检索默认截止今天（北京时间），不展示来源标注的未来发表日期。OpenAlex与顶会索引仅匹配标题和摘要；旧版全文查询缓存不再预览。可组合多个关键词缩小检索范围。关键词命中不等于模型判断主题相关。
