# 选择适合自己的版本

需要随时查看公共论文库、无需安装：选择 **GitHub 网页版**。需要任意主题实时访问来源、独立推荐偏好或飞书：选择 **本地版**。

## 本地版

浏览器请求本机 FastAPI 服务，服务访问各来源，合并论文并返回结果。推荐设置与历史存储在本机，飞书可选。关闭本机服务后，检索、定时推荐和机器人暂停。

## GitHub 网页版

GitHub Actions 采集公共 AI 分类与论文列表 → 保存公共论文 JSON 和推荐历史 → GitHub Pages 发布静态页面 → 访客在浏览器搜索该论文库。

网页只包含 HTML、CSS、JavaScript 和公开 JSON，不连接本地服务，不连接飞书，不接收访客的服务端任务。浏览器输入不会触发远端即时采集；修改筛选只影响当前页面，不修改其他人的偏好。

采集工作流使用 Python 来复用已验证的来源适配器，运行后退出。因此“纯静态网页”不等于“整个仓库只有 JavaScript”。无需另外购买常驻服务器。

## 搜索与推荐的不同

本地版从来源实时获得有限候选，按来源排名融合或日期排序。网页版在有限公共论文库里使用 Okapi BM25；先要求查询词全部匹配标题与摘要，再支持按相关性或日期排序。支持 LLM/LLMs 与 large language model、SVD 与 singular value decomposition 的归一化。不使用向量或语义模型，未收录的论文无法搜出。检索库不设统一起始日期，但各接口每轮仅取有限候选；顶会按会议分别浏览，OpenReview 可切换已录用与公开投稿。

网页版没有预设个人主题。推荐从本轮成功采集的公共 AI 候选中，选取来源标注日期为当天的论文，各来源全部符合条件的已取得论文；无新论文不补足。当天重跑不会创建第二条同日记录。失败来源显示失败；搜索库累计保留历史元数据，但不把旧候选作为新一天的推荐。部分失败不影响其他来源。

本地版推荐设置支持更多个性化项，使用现有规则评分；网页版不是全部后台能力的等价替代。

## 发布与隐私

仓库根目录同时分发两种源代码；只有 `web/` 发布到 Pages。个人配置、飞书密钥、推荐私有历史、运行日志、缓存和虚拟环境不在发行包中。

网页版论文库和采集配置是公开站点内容。需要扩展范围可以 Fork 自己维护；需要私有阅读记录请使用本地版。默认部署链接在 Fork 后需改成自己的用户名与仓库名。

## 两版同步的累计论文库

本地工作台新增“打开本地累计论文库”，地址 `/library/`，与网页版共享会议目录、OpenReview 已录用/公开投稿、DBLP、分页历史补采、进度、无篇数截断的当日列表和日期计数。数据保存在本机 `local/data/library/`，不会读取或上传个人飞书、推荐或搜索记录。保留原 React 工作台的实时检索和个人主题推荐；个人推荐的 0 篇设置表示展示全部已取得的匹配候选，实时来源的覆盖限制仍需查看状态。

下载时保留整个仓库结构：`local/` 的累计库需要根目录的 `scripts/`、`config/` 和 `web/`。不能只拷贝 `local/` 子目录。云端由 Actions 运行，本机由 FastAPI 后台任务运行；只使用其中一版不需要运行另一版。


每日日期浏览：累计论文库的“每日推荐”列出当前来源所有已收录且有明确日期的论文日期，不受推荐生成历史或 30 天窗口限制。“全部日期”按论文标识去重；单日列表按该来源标注日期分组，每个选项显示实际收录篇数。历史浏览不代表当时已生成推荐，也不保证该来源当天的全部论文已收录。两版共用此页面；本地个人主题推荐仍保留独立的生成记录。


累计论文库同步支持官网公开清单、可点击会议卡片、按会议年份筛选、零收录日期与按需加载/预取缓存。会议官网每天 09:00 检查，跨年自动选择新年并尝试从官方首页发现改址；入口无法识别时保留旧数据并显示待更新。来源覆盖及限制见仓库 `docs/github-pages.md`。
